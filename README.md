# Mobile Login App - Java Android
Este proyecto hace parte de una actividad sena, *Creación de una aplicación movil usando Java* 
Se conecto al api construida en Laravel y solo permite el *inicio de sesion*

## Descripción
La aplicación fue desarrollada con el objetivo de demostrar la integración entre una aplicación móvil construida en Java y un API REST desarrollada en Laravel.

Actualmente el proyecto implementa únicamente el módulo de autenticación, permitiendo realizar el inicio de sesión mediante consumo de servicios HTTP hacia el backend.

## Funcionalidades
Inicio de sesión de usuarios
Consumo de API REST
Validación básica de credenciales
Manejo de respuestas HTTP
Integración entre Android y Laravel


# Tecnologías utilizadas
## Frontend móvil
Java
Android Studio
XML para interfaces gráficas

## Backend
Laravel
API REST
MySQL


# Objetivo del proyecto

El propósito principal de este proyecto fue validar conocimientos en:

- Desarrollo móvil con Java
- Consumo de APIs REST
- Comunicación cliente-servidor
- Integración entre tecnologías
- Manejo básico de autenticación
